Reference: ChatGPTFarm-Architecture-Blueprint.pdf, 30 pages, 19 September 2026, reviewed PR #10 at 557729b4. All sections read before this checkpoint. This map preserves the whole direction, not only the initial bug fixes. Release evidence remains in REBUILD_STATUS.md.

## Product clarification takes precedence

The live village follows physical constraints, natural variation and agent motivations. Do not manipulate supplies, weather, memories or outcomes to make an experiment succeed or fail. Controlled tests and Decision DNA interventions run on isolated copies, with separate budgets. Decision DNA supports evidence and diagnosis; it is not the purpose of the world or a director of its story.

## Architectural commitments

- Keep JS runtime/Cloudflare durable owner and independent viewer; introduce typed contracts incrementally. No wholesale engine/language rewrite, distributed cluster, vector database or agent framework without a demonstrated need.
- Distinguish simulation, cognition, runtime, presentation and experiments within this repository. One world authority; model outputs are validated proposals.
- Separate simulation time, wall time, decision latency and frames. Archive accepted model outputs for replay; do not rerun inference and call it the original past.
- Use conserved materials and stable entity identities across holders. Mark legacy conversion assumptions; unknown provenance remains unknown. No material creation from zooming, inspecting or migration.
- Preserve private observations/beliefs/procedures/commitments. Learned skills require practice; model pretraining is not proof of lived learning. Keep motives broad and continuous, not a technology-unlock quest.
- Construction programs have bounded operations and access only to observed capabilities; no host code, network, secrets, direct state writes or self-declared success.
- Separate unsupported engine actions from physical failure and insufficient agent knowledge.
- Preserve current people/history and accepted popup work. PR #8 is selectively adapted, never a wholesale future merge. Chronicle remains a projection until a permanent archive exists. Rejected clay PR stays excluded.
- Art is replaceable and physically grounded. Semantic asset manifests, stable variation, shared scale and animation rigs. No generated still image substituted for a live renderer. Babylon prototype is a recommendation to evaluate, not a production migration already approved by evidence.
- Keep one region owner until profiling shows a need to split. Future transfers preserve IDs and quantities; coarse/detailed simulation must agree on accounts.
- Survival includes impairment eventually, but do not retroactively kill people because old approximate meters reached zero. Need faithful inputs before adding consequences.

## Deferred decisions and optional directions

Record starting knowledge, failure/mortality policy and simulation pace before interpreting civilization outcomes. They do not block pure-read repairs. Teaching, traditions, repair/reuse, specialization, gifts, reputation, maps and archaeology are opportunities for emergence, not mandatory quests. Defer reproduction, complex disease, metallurgy, markets and large populations until prerequisites work.

## Verification and release

Separate mechanics tests, runtime/recovery tests, isolated model experiments and human visual review. Measure conservation, time consistency, local knowledge, learning, travel/work, archive completeness, and cost; do not optimize only for zero deaths. Adversarial fixtures never alter production. Version schemas/rules/prompts/assets separately. Rehearse migration and rollback or forward repair; a graphics rollback must not roll back history.

Before each release, pin tested SHA, verify current-state migration and affected projections, document remaining approximations, and record actual runtime deployment separately from Git merge. See REBUILD_STATUS.md for the current HOLD.
