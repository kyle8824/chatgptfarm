# v1.6.8 — persistent survival actions — released and verified

Acceptance target: travel before benefits; food/water/warmth changing during activity; urgent needs interrupting longer work; truthful AI/fallback status. No graphics redesign or world replacement.

## Changes

The authoritative Cloudflare runner now executes persistent tasks in five-simulated-minute steps inside its existing 150-second/hour persisted transition. A task retains its identity, route, work progress and any partially consumed portion across hour boundaries and restarts. Routes respect the canonical creek and explicitly blocking footprints; distance, the existing two-metres-per-unit scale and carried mass determine progress. Destination effects require arrival and work. Contention uses a documented rotating identity order, independent of array order.

Eating, drinking and rest apply fractions during work. Needs drain and thermal exposure apply over elapsed steps; travelers receive no camp heat before arriving. Food is removed once into a retained portion, preventing double consumption after reload. Urgent needs suspend longer tasks and retained work can resume. Short recovery actions finish instead of endlessly interrupting each other. Shared food transfers portions for the recipient to eat later.

The spectator receives only elapsed substeps and follows the engine's route. Within-hour updates refresh activity and need meters; original wildlife motion remains operational. AI diamonds/model labels now describe the actor's actual decision source rather than advertising AI for fallback agents. Health reports enabled/key-present flags, model, mode and fallback reasons without disclosing credentials. Dashboard settings and call caps remain unchanged; at most one fresh model proposal per actor per simulated hour is attempted, with local execution between proposals.

Completed evidence remains useful for action/decision linkage and AI diagnosis. It is now explicitly bounded to the latest 256 completed transitions. Older diagnostic segments are retired transactionally. This is not a permanent archive; external backup, replay experiments, reflection and broader Decision DNA work are deferred and are not release prerequisites under Kyle's clarified scope.

## Explicit limits

Five-minute stepping rounds travel/work to the simulation resolution; this is not continuous physiology or full terrain physics. The current creek and explicit blockers are respected; slopes and decorative trees without collision geometry are not invented obstacles. Work durations, walking/load response and need rates are coarse model assumptions. Existing recipes still resolve their physical outputs at completed work; this does not implement generic construction or learned plans.

The runner precomputes and persists the next hour's deterministic substeps. Interruptions respond to simulated needs within those substeps; it is not a live external-event scheduler. Previously buffered v1.6.7 transitions finish unchanged on upgrade, so the new behavior appears after that buffer drains. Pause/resume shifts the wall-clock interval while retaining action progress. Do not roll code back to the legacy action executor after new task state has been saved; use a forward fix. Keep FarmWorld / preview-v1 and all existing identities/history.
